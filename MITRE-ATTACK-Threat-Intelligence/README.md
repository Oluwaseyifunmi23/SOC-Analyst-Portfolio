# MITRE ATT&CK Threat Intelligence Investigation

## Project Overview

This project documents my practical learning and investigation
using the MITRE ATT&CK Framework through TryHackMe.

The objective was to understand adversary behaviours, investigate
threat groups, identify attack techniques, and explore defensive
strategies for improving organisational security.

## 1. Threat Group Investigation

Investigated APT33, an Iranian threat group known for targeting
the aviation and energy sectors.

Activities included:
- Investigating APT33 (G0064).
- Reviewing its documented attack behaviours.
- Identifying associated techniques and software.

## 2. ATT&CK Techniques

Investigated:

- Valid Accounts (T1078).
- Cloud Accounts (T1078.004).
- Ruler as an associated tool.

Explored how adversaries can abuse legitimate cloud accounts
to access organisational resources.

## 3. Mitigation Strategies

Identified:

- M1018 - User Account Management.

Explored the importance of reviewing user accounts and
removing or disabling inactive accounts.

## 4. Detection Strategies

Investigated detection strategy:

- DET0546.

Explored how detection strategies can support the identification
of abused or compromised cloud accounts.

## 5. MITRE Cyber Analytics Repository (CAR)

Investigated:

- CAR-2019-07-001
- Access Permission Modification
- Associated ATT&CK tactic: Defense Evasion.
- Analytic Type: Situational Awareness.

## 6. Other Frameworks and Security Concepts

Also explored:

- MITRE D3FEND.
- MITRE CALDERA.
- Adversary Emulation.
- Credential Rotation.

## 7. Key Learning Outcomes

Through this exercise, I strengthened my understanding of:

- Threat intelligence investigation.
- Adversary behaviour analysis.
- MITRE ATT&CK navigation.
- Cloud account security.
- Security detection and mitigation.
- Defensive security concepts.
